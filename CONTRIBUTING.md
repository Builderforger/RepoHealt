# Как присоединиться к работе

## С чего начать

Поднять всё целиком:

```bash
cp .env.example .env
```

Вписать в `.env` токен SourceCraft, затем:

```bash
docker compose up --build -d
```

Подробнее — в [README](README.md).

## Где что лежит

| Куда смотреть | Если меняете |
| --- | --- |
| `backend/src/RepoHealth.Scoring` | методику расчёта |
| `backend/src/RepoHealth.Collection` | сбор данных |
| `backend/src/RepoHealth.Contracts` | состав фактов или отчёта |
| `web/app` | сайт |
| `docs/` | документацию |

Прежде чем менять методику, прочтите [docs/methodology.md](docs/methodology.md):
там объяснено, почему веса и пороги именно такие.

## Правила, которые важнее остальных

**Расчёт не ходит в сеть и не смотрит на часы.** В `RepoHealth.Scoring`
не должно появиться ни обращений к API, ни `DateTimeOffset.Now`.
Момент времени приходит во входных фактах. На этом держится
воспроизводимость оценок и возможность проверять методику тестами.

**Отсутствие данных — не ноль баллов.** Если данные не удалось
получить, часть оценки исключается из расчёта, а категория получает
статус «нет данных» с понятной причиной. Ноль означает «плохо»,
и ставить его за молчание API нельзя.

**Каждая часть оценки объясняет себя.** К любому баллу прилагается
текст с конкретными числами, понятный человеку без чтения кода.

**Секреты не попадают ни в код, ни в аргументы команд, ни в отчёты.**
Токены передаются только через переменные окружения. Если токен
может оказаться в тексте ошибки — его нужно оттуда вырезать.

## Перед отправкой изменений

```bash
cd backend && dotnet test
```

Все тесты должны проходить. Изменение методики без теста
на новое поведение не принимается: методика — главная ценность
проекта, и она защищается тестами.

## Оформление

Сообщения коммитов на английском, в повелительном наклонении,
с типом впереди:

```
feat: add security category from AppSec scan results
fix: write reports one per line so the site can load them
docs: describe scoring methodology
```

Комментарии в коде и тексты для пользователя — на русском.
Комментарий объясняет, **почему** так сделано, а не пересказывает
код.
