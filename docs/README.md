## Коротко о главном

Сервис регулярно обходит открытые репозитории SourceCraft, считает
для каждого оценку здоровья от 0 до 100 по шести категориям,
объясняет каждый балл и выдаёт рекомендации, отсортированные
по пользе.

Три решения, которые определяют всё остальное:

**Расчёт отделён от сбора.** Методика не ходит в сеть и не смотрит
на часы, поэтому проверяется тестами и даёт воспроизводимый
результат.

**Отсутствие данных не штрафуется.** Категория без данных получает
вес ноль, её вес переходит остальным, а рядом с оценкой написано,
по скольким категориям из шести она посчитана.

**Оценка объясняет себя.** У каждой части есть текст с конкретными
числами, а каждая рекомендация опирается на факт из отчёта
и обещает честную прибавку в баллах.
